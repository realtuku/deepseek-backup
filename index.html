DeepSeek Backup

A lightweight Python toolkit to backup every DeepSeek chat to individual .txt files — with timestamps and chat-start times. 100% local. Zero vendor lock-in.

Get started View on GitHub

Why DeepSeek Backup?

DeepSeek does not provide a chat export or backup feature. If you have hundreds of conversations with code, ideas, research, and late-night thoughts — they live and die inside the browser.

This project was born from real frustration. It started as a fragile Selenium scraper and evolved — through trial, error, and DevTools spelunking — into a clean, direct-API backup solution.

No browser automation. No DOM scraping. No selectors that break next week. Just pure HTTP, verified against the live API.

The problem: Your DeepSeek chats are trapped in a browser session. No native export. No backup. One logout = loss of history.

Key features

Direct API access

Uses DeepSeek's own /api/v0/ endpoints — no Selenium at runtime. 50x faster than scraping.

One file per chat

Each conversation gets its own .txt file, named after the title. Easy to organize and search.

Full timestamps

12-hour format hh:mm:ss AM/PM - dd mm yy per message. Know exactly when each thought was captured.

Smart sorting

Pinned chats first, then newest-first. Your most important conversations are always accessible.

Auto credential grabber

Separate script grabs token + cookies from Chrome. Zero manual copy-paste needed.

Windows 10 friendly

Runs perfectly from Python IDLE. No complex setup. Auto-installs dependencies.

Quick start guide

01

Clone the repo

Get the latest code from GitHub and navigate to the directory.

git clone https://github.com/realtuku/deepseek-backup.git
02

Get your credentials

Run the helper script — it opens Chrome and auto-grabs your token.

python get_credentials.py
03

Configure the script

Paste your credentials into the CONFIG block in deepseek_backup.py.

AUTHORIZATION = "Bearer ..."
04

Run the backup

Execute the main script to backup all your DeepSeek chats.

python deepseek_backup.py
05

Check output

All your chats are now backed up in the deepseek_backups/ folder.

ls deepseek_backups/

Output format

Each backed-up chat is saved as a well-formatted .txt file with timestamps and metadata.

Frequently asked questions

Is my token secure?

Your token is a session key — keep it private. Never commit credentials to GitHub. The .gitignore file excludes credentials.txt by default. If you accidentally expose it, log out and back into DeepSeek to rotate the token.

Does this require Selenium?

No! Unlike earlier versions, the main deepseek_backup.py script uses pure HTTP via the requests library. Only the optional get_credentials.py script uses Chrome automation to grab credentials — and that's only needed once.

How fast does it backup?

Incredibly fast. Direct API access means 30 chats back up in ~15 seconds. No DOM scraping, no delays. There's a small REQUEST_DELAY between API calls to be respectful to DeepSeek's servers.

What if the API changes?

If DeepSeek changes their API, pull requests are welcome! This is an open-source project. The API contract is verified against live data, so we catch breaks quickly.

Do I need internet?

Yes, to backup your chats from DeepSeek's servers. But once backed up, the .txt files are 100% local and don't require any internet connection to read or search.

Is it free?

Completely free! MIT License. Use, modify, and distribute as you like. Attribution appreciated but not required. This is a community project built with frustration and love.
